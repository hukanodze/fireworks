# 🎆 Фейерверк

Интерактивный сайт с фейерверками: разные формы, цвета и физика частиц.

## Возможности

- **8 форм салютов** — Сфера, Кольцо, Двойное кольцо, Сердце, Звезда, Ива, Пальма, Крест
- **5 палитр** — Радуга, Тепло, Холод, Неон, Золото
- **Авто-режим** с регулятором частоты и кнопкой «Залп»
- **Управление** — клик по небу запускает салют в точке клика, пробел — случайная форма, клавиша H скрывает панель
- Физика: баллистический полёт ракет, гравитация, сопротивление воздуха, мерцание искр
- Эффекты: вспышка взрыва, лёгкая тряска экрана, искры за ракетой, мерцающие звёзды

## Запуск

Ни зависимостей, ни сборки — один файл:

```bash
# просто откройте index.html в браузере
```

Либо через любой статический сервер:

```bash
npx serve .
```

## Технологии

- Canvas 2D
- Чистый JavaScript без библиотек
- Адаптив под размер окна и Retina-экраны
